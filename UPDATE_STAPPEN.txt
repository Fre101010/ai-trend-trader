PERSISTENTE OPSLAG VIA SUPABASE
1. Maak een Supabase-project.
2. Open SQL Editor.
3. Voer SUPABASE_SQL.sql uit.
4. Noteer Project URL en service_role key.
5. Voeg in Streamlit App > Settings > Secrets toe:
   SUPABASE_URL="jouw-url"
   SUPABASE_KEY="jouw-service-role-key"
6. Voeg dezelfde 2 waarden toe in GitHub > Settings > Secrets and variables > Actions.
7. Ga naar GitHub > Actions > Paper Trader Hourly > Run workflow.
8. Als de run groen is, kan de paper-run daarna elk uur automatisch draaien.
